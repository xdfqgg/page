# Proper Noun Glossary / 专有名词注释

## 规则

在本次对话中，**首次出现**的专有名词（缩写、外来词、技术术语、品牌名、项目名等），必须紧跟在它第一次出现的位置，给出：

1. **全称** —— 如果是缩写，写出展开后的完整名称
2. **中文翻译** —— 对应的标准中文译名，如果没有标准译名则给出贴切翻译
3. **一句话解释** —— 用口语化的方式说明它是什么

## 格式

```
第一次出现时 → 专有名词（全称 / 中文名 / 一句话解释）
后续出现时 → 只写专有名词本身，不再重复注释
```

## 示例

用户说："帮我配一下 DNS"

我答："好，先看 DNS（Domain Name System / 域名系统 / 把网站域名翻译成 IP 地址的服务器，相当于互联网的电话本）配置……"

用户说："开启 TUN 模式"

我答："TUN（Tunnel / 隧道 / 一种虚拟网卡技术，在操作系统层面劫持所有网络流量，让不走代理的程序也能被梯子接管）模式已开启……"

## 生效范围

- 技术术语：DNS, IP, TCP, TLS, VPN, TUN, CDN, GFW
- 工具/品牌名：Clash, V2Ray, Shadowsocks, WireGuard, PowerShell, curl
- 项目/系统名：如果上下文中有项目代号或内部系统名
- 不生效：日常用语、已经大众化的词（如 WiFi、App）、对话中已经解释过的词

## 例外

如果用户明确说"不用解释了"或者"这个我知道"，跳过注释。
